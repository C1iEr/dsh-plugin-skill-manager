# Skill Manager for DeepSeek Harness

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一个给 **DeepSeek Harness (DSH)** 用的技能管理插件：把「模型这一轮能看到哪些 Skill」
变成会话里随时可调的开关。

A DSH plugin that turns *which skills the model can see this turn* into switches you
can flip inside the conversation.

---

## 它做什么 / What it does

| 功能 | 说明 |
| --- | --- |
| 每会话独立 | 状态按会话 id 存，A 会话关掉的技能不影响 B 会话 |
| 总开关 | 关掉后本会话的模型既看不到技能目录、也加载不了任何技能 |
| 逐技能开关 | 列表里一行一个开关，随时开/关，不删除文件、随时可逆 |
| 分组 | 把若干技能收进一个命名组，点组名整组开关；多个组可并集生效 |
| 自动选择 | 每轮按用户消息挑相关技能，其余不列出；一个都没命中时退回全部 |
| 详情 | 点技能名看它真正的内容（来源、路径、Markdown 原文） |
| 搜索 | 按名字或描述过滤 |
| 体量估算 | 显示技能目录大约占多少 token，方便判断该关谁 |

界面在输入框工具条上（「完全权限」右侧）是一枚紧凑胶囊，点开是管理面板；
模型选择菜单里另有两条同款的滑动开关。

## 安装 / Install

这是一个 **bundle**（`package.json` 里带 `dsh.bundle.patch` + `dsh.client`），
不是普通 npm 包。安装它需要一个能装 bundle 的 DSH 环境：

1. 把本仓库克隆/解压到本机任意目录（路径不要带空格更稳）；
2. 在 DSH 里用 **插件管理器**把这个目录作为 bundle 安装（面板操作，或调用
   `plugin_manager` 的 `install_bundle`）；
3. 安装后在 `插件` 面板里应能看到 **Skill Manager**，输入框工具条上会多一枚胶囊。

> 说明：本文档不写死 CLI 命令 —— 不同 DSH 版本的插件子命令名称不一样，
> 以你本机插件面板/管理器的实际入口为准，避免照着一行跑不通的命令来回试。

本插件无第三方运行时依赖，只用 `node:fs` 与 DSH 自己的 Cordis 接口。

## 工作原理 / How it works

### 不接管渲染，只遮蔽条目

DSH 的技能目录在 `agent/pre-step` 里生成。第一版试过「注册自己的 `skill` 工具
把自带的顶掉」，结果自带工具仍会把目录换成空目录 —— 此路不通。

现在用的是技能注册表的分层规则：

- `ctx.skills.register()` 把条目登记进**调用上下文所在的层**；
- agent 作用域比 host / preset 层更靠近观测点，**同名条目直接胜出**；
- `invocation: { modelInvocable: false, userInvocable: false }` 的条目不会进模型目录。

所以「关掉某个技能」= 在 agent 作用域注册一条同名的遮蔽条目。目录、摘要、
替换消息、指纹全部由 DSH 自己维护，本插件不复制任何上游逻辑。

### 时序

遮蔽必须在 pre-step 之前落到注册表上，钩子是 `agent/inbox/claimed`
（用户消息被本轮领取时）。插件热重载后 `agents.list()` 可能暂时为空，
所以另挂一个惰性补挂：真有消息进来时一定能把闸门建起来。

## 默认值与优先级 / Defaults

- **默认：每个会话 0 个手动启用 + 自动选择开着。** 新会话不会一口气把全部技能打开；
  打开面板看到的是「自动挑」的状态 —— 要自己点名控制，先关掉「自动选择技能」。
- **自动选择的结果优先。** 手动开关和已启用的编组只是**加权参考**：它们影响倾向，
  不决定结果。所以不会出现「因为我开着编程组，所以写文章时也只能拿到编程技能」。
- **编组可多个并集生效。** 点一个组只启用该组成员、组外技能全关；再点开第二个组会并进来。
- **编组优先匹配。** 自动选技先看有没有现成编组能覆盖这一轮的任务（组名 + 组说明 +
  成员描述的加权匹配），命中就整组上；没命中才逐个挑技能。

## 已知边界 / Known limits

- 匹配是**词面**方法（中文二字组 + 停用词过滤 + 覆盖率），不做语义向量、不调模型 ——
  这一步在请求前的同步路径上，加 LLM 调用等于把首字延迟翻倍。代价是上下文依赖的
  请求（「把第 3 页放大一点」）判不出来，会退回全部技能。
- 技能名必须是 kebab-case ASCII（`^[a-z0-9][a-z0-9._-]*$`）。中文 `name:`
  会被 DSH 的注册表静默丢弃 —— 装了多少都不会出现在目录里。
- 状态存在 `$DSH_HOME/skill-manager/state.json`，是纯文本，可手工编辑或备份。
